# 🤖 Smart Surveillance Robot

An intelligent mobile surveillance robot based on Arduino and ESP32-CAM, designed for remote monitoring, live video streaming, obstacle detection, and smart movement.

## 📌 Project Overview

The Smart Surveillance Robot is a robotics project that combines embedded systems, wireless communication, camera-based monitoring, and obstacle detection. It aims to provide a mobile surveillance platform for monitoring environments remotely.

## ✨ Features

- 📹 Live video streaming using ESP32-CAM
- 🚗 Motorized robot movement
- 🚧 Obstacle detection and avoidance
- 📡 Wireless monitoring and control
- 🔊 Audio module integration
- 📟 Display integration
- 🔧 Modular hardware design

*Features depend on the final hardware assembly and implemented code.*

## 🛠️ Hardware Components

- Arduino board (if used in the final circuit)
- ESP32-CAM module
- DC geared motors
- Motor driver module
- Robot chassis and wheels
- Obstacle detection sensor
- Power supply or battery
- Jumper wires
- Audio and display modules (optional, according to the final design)

## 💻 Software Requirements

- Arduino IDE
- ESP32 board package for Arduino IDE
- Required sensor and camera libraries
- Web browser for viewing the camera stream
- USB-to-serial programmer, if required by the ESP32-CAM board

## ⚙️ Working Principle

1. The controller receives commands for robot movement.
2. The motor driver controls the DC motors.
3. The obstacle detection sensor measures the distance to nearby objects.
4. The ESP32-CAM captures video and provides a live stream over Wi-Fi.
5. The user can monitor the surroundings and control the robot using the implemented interface.
6. Optional audio and display modules provide additional functionality when configured.
